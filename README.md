- Detalles del proyecto

Miku Bookstore es una librería de útiles escolares. Este repositorio contiene su página principal.

- A quién está dirigido

- Padres, madres y tutores que compran útiles para sus hijos.
- Estudiantes de kinder, primaria y secundaria.
- Docentes y escuelas que necesitan materiales para sus aulas.

- Cuál es el propósito

Ofrecer en un solo lugar todos los útiles escolares que necesita cada nivel educativo, con productos de calidad, buenos precios y una compra fácil y rápida.

- A qué da solución

- Evita recorrer varias tiendas para completar la lista de útiles.
- Organiza los productos por nivel escolar.
- Ahorra tiempo y dinero en la temporada de inicio de clases.
- Facilita comprar con anticipación.

- Finalización (16 Nov)

- Página realizada

Página principal (index.html) con estilos en style.css.

- Estructura semántica: header, nav, main, section, article y footer.
- Tabla de ofertas con caption, thead y tbody (4 columnas, 3 registros).
- Formulario de contacto con label, select, textarea y validaciones HTML5 (required, minlength, pattern).
